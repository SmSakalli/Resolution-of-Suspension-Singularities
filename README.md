# Resolution-of-Suspension-Singularities

PrintGraphwithArrows.m and PrintGraphCompactified.m: Magma programs to construct minimal resolution graphs of suspension singularities. PlotGraph (Sage): A SageMath program to produce graphical representations of the resulting resolution graphs. The SageMath program PlotGraph NoColor produces black-and-white versions of the graphs.

IsomorphismCheck.m: A Magma program that checks the isomorphism of resolution graphs of closed fibers over a specified parameter range.
